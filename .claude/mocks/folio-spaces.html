Spaces, focus, switcher, command bar

Click the stage first so it has the keyboard. Hold ⌥ and press Tab for the switcher (arrows move into a project's workspaces; let go of ⌥ to jump). ⌥Space opens the command bar. In a space, ⌘S or the window's left edge shows the sidebar. Right-click a project mark, or use × on the menu bar's focus chip, to unfocus. All data is example data.
